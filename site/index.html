gritjitsu is Jujutsu with gitoxide and the git executable swapped out for grit-lib, a pure-Rust Git implementation. Same commands. Same commit ids. Clones about 3× faster.

cargo build --release see the numbers

02 / footprint

One binary. Nothing else to install.

Upstream jj links gitoxide and still shells out to Git 2.42+ for fetch, push, worktrees and gc. gritjitsu needs neither.

jj + gitoxide + git CLI
98.0 MB
jj + grit-lib
35.3 MB

macOS arm64 release builds. Git measured as a Homebrew 2.56 install (70.1 MB).

0 gix crates

Objects, refs, index, config, transport: all grit-lib. Nothing from gitoxide in Cargo.lock.

Same commit ids

Commits are written byte-for-byte as before. Your existing repos keep working.

Reftable + SHA-256

Colocated repos with reftable refs work, which upstream jj doesn't support yet.
